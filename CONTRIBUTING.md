# Contributing to Awesome Project I.G.I.

Contributions are warmly welcomed! Please follow these guidelines when suggesting a new project, tool, or resource.

---

### Inclusion Guidelines

1. **Relevance**: The project must directly relate to *Project I.G.I.: I'm Going In* (2000), *I.G.I.-2: Covert Strike* (2003), or their underlying Innerloop Studios engine technology.
2. **Legal & Ethical Compliance**: Projects must **not** host, distribute, or redistribute copyrighted game assets, proprietary binaries, or retail data files. All projects must require user-supplied legally owned copies of the game.
3. **Open Source & Transparency**: Prefer projects with public source repositories (GitHub, GitLab, etc.) or well-documented web demonstrations.
4. **Active & Functional**: The project should have demonstrable progress, runnable code, or clear documentation.

---

### How to Submit

1. **Fork** this repository.
2. Create a new branch:
   ```bash
   git checkout -b add-my-project
   ```
3. Add your project under the most appropriate category in `README.md` using the standard format:
   ```markdown
   - **[Project Name](https://github.com/user/project)** `Tag1` `Tag2` — Concise description of the project, architecture, features, and key technologies. By [@Author](https://github.com/Author).
   ```
4. Keep the list sorted alphabetically or by significance within its section.
5. Test that your markdown links work.
6. Commit your change:
   ```bash
   git commit -m "feat: add [Project Name] to [Category]"
   ```
7. Open a **Pull Request** explaining your contribution!
